FIREBASE RULES FOR TESTING CUSTOMER ORDER CREATION

Because the customer app sends orders without a Firebase login, production-mode rules can block the SEND ORDER button.

For TESTING ONLY, in Firestore > Rules, use:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /orders/{orderId} {
      allow create: if request.resource.data.status == 'NEW';
      allow read, update: if request.auth != null;
    }
  }
}

After testing, replace this with stricter rules. Do not leave public order creation open permanently.
