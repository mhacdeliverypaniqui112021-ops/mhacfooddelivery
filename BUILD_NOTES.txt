MHAC DELIVERY V4.1.74 — COMPACT STORE / FOOD EDITOR UPDATE

Changes in this build:
- Deleted choice groups no longer reappear automatically when a food editor is reopened.
- Existing foods show only their saved choice groups; use ADD CHOICE GROUP to add one again.
- Choice name input is wider so long names are easier to see/edit.
- Choice price input is narrower to save horizontal space while still supporting additional fees.
- Chicken Parts keeps a wide name field with a compact delete button.
- No Description field and no food photo were added.
- Existing Admin/Rider order flow is preserved.
Choice field sizing update: Choice Name is the wide field; Price is compact at 62px, intended to fit 3-digit prices such as 35, 100, 999 without stealing space from the choice name.
