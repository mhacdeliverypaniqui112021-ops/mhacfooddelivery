MHAC ADMIN — ALL CHOICE GROUPS COPY/PASTE

Every Choice Group in the Food Editor now has:
- COPY CHOICES
- PASTE CHOICES

Examples:
- Drinks
- Part
- Fries
- Add-ons
- Any new/custom Choice Group

Copy preserves option names and prices. Paste replaces only the options
inside the selected Choice Group. The group name itself is not changed.

Protected:
- Customer is not included or modified.
- Existing Admin features remain unchanged outside this Choice Group editor addition.
